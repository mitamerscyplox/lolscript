Preparation

Before you start

Run the Perm Spoofer and Vanguard Emulator guides first if you bought the full stack. Use only the current loader from official LOLScript support.

  1. Confirm active access

    Keep your checkout email or Discord username handy so access can be matched quickly after purchase.

  2. Prepare your Windows PC

    Use a current Windows 10 or 11 build with League of Legends installed, updated, and opening normally through the Riot client.

  3. Update runtime dependencies

    Install the latest Visual C++ redistributables and .NET components when support requests them.

  4. Join official support

    Open Discord with your order email, Discord username, and plan length for fast verification and the current file link.

  5. Get the current files

    Use the official loader link from support only. Avoid old builds, reposted archives, or third-party mirrors.

Installation

Step-by-step installation guide

Follow these steps in order after checkout. Ask support in Discord before changing BIOS or security settings you do not understand.

Step 1

BIOS settings

Use UEFI boot mode. CSM should be disabled or set to UEFI-only.

Step 2

Windows settings

Use the latest Windows 10 or 11 build with all updates installed. Contact Discord support if Windows Security blocks setup.

Step 3

Format your USB drive

Format your USB stick as FAT32 before copying loader files. Use a clean drive with no old boot folders.

Step 4

Download loader

Download lol_script.rar from the official support link. Archive password: 123. Run Loader.bat and enter your license key.

Step 5

Set USB boot order

Enter BIOS (DEL, F2, or F8). Set boot order: 1. UEFI USB stick, 2. Windows Boot Manager, 3. other devices.

Step 6

Start the game

Boot from the prepared USB drive, then start League of Legends normally. The script activates when USB boot setup loads correctly.

Before your first game
  • Only use the loader link sent through official LOLScript Discord support.
  • Start with default settings, then tune one feature at a time.
  • Test in practice tool, a custom game, or normals before ranked.

Configuration

  2. Create your first config

    Select a champion preset, check hotkeys, tune core features, then save the profile.

  3. Test in a low-pressure mode

    Use practice tool, a custom game, or normals first before ranked.
